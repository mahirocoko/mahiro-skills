## Lessons Learned

- When an installed skill and the repo disagree, the repo commit is the contract. Check `git log` before inventorying lanes from the installed copy.
- A catalog default effort is not the skill role. If Mahiro adopts a new model without naming effort, keep the previous role's effort and record the catalog default beside it.
- Do not copy a model ID onto an executor whose live catalog does not list it. Agy stayed on Sonnet 4.6. The source-art route stayed on `gpt-5.6-sol`.
