## Lessons Learned

- Usage frequency is evidence, not the sole deletion criterion; explicit-trigger and one-time safety skills need uniqueness/risk weighting.
- A retained compatibility-looking skill must own a real additional job; for `watch`, that job is YouTube metadata, captions, and durable local learning capture.
- Retired-skill regressions should guard exact package/route identifiers, not generic English words.
- Split multi-owner catalog migrations into smaller patches because partial patch application can leave an intermediate inconsistent tree.
- Static route parity is not authenticated provider-runtime proof.
