## Architecture Decisions

- Historical artifacts are evidence, not behavioral authority.
- RRR owns retrospective history and may optionally capture gated non-canonical reference material; it never approves guidance.
- Durable promotion belongs to `mahiro-guidance-refine` and requires an observable shared contract plus explicit owner approval.
- Consolidation precedes creation, and No-op is a valid outcome.
- Incident chronology and absent mechanisms stay out of canonical guidance unless they are themselves stable, recurring triggers.
- Adjacent skill schemas remain a separate Phase 5 scope rather than being silently changed during this batch.

## Honest Feedback

The first friction point was administrative overhead in evidence attachment. Each Goal criterion required separate evidence and claim mutations, which produced a large amount of state churn for a documentation-contract change that had already passed a coherent verifier. The evidence was valuable, but the granularity was disproportionate. Second, the human gate exposed a real capability gap: Mahiro's direct acceptance could be stored as user evidence, yet the tool still left the criterion pending and offered no agent-callable human-verification action. That made the displayed Goal state less truthful than the conversation. Third, the initial verifier correctly challenged bundle-wide authority consistency because Watch and Learn write unlabeled learning artifacts. The approved scope explicitly made those read-only follow-ups, so the correct response was not to dismiss the finding or expand silently; it was to narrow the Batch claim and preserve the follow-up. Future missions should separate “this batch is internally aligned” from “the whole bundle has completed migration” directly in the DoD wording.

## Lessons Learned

- Define artifact authority before adding more durable memory producers.
- A retrospective can be complete without producing any new lesson file.
- Promotion needs future applicability, scope reality, operational shape, novelty, consolidation, and human approval.
- Active descriptions and catalogs are contract owners too; stale summaries can undo canonical guidance.
- Human acceptance evidence and structured human verification are different runtime capabilities and should not be conflated.

## Learning Promotion Decision

The reusable decisions from this session are already expressed in the updated canonical skills, authoring docs, and regression tests. Creating another reference-learning file would fail the novelty gate and duplicate the approved owner rather than add useful evidence.
