Mahiro-local changes: one entry with four progressive lanes; current user and
repository contracts remain higher authority; preserve real features, facts and
working behavior; do not install missing tools automatically; treat app/dashboard
shells as product surfaces rather than decorative outer cards unless product context
proves otherwise; classify visible badges/icons/controls before removal; require
semantic colors to separate visibly from secondary text in rendered context; reject
orphan signature marks and redundant pseudo-elements; require rendered runtime
evidence and keep Mahiro's visual/product acceptance human-owned. The UI
reference has a short port-boundary preface and omits only upstream frontmatter and
provider-specific `agents/openai.yaml`; Markdown link destinations are normalized
for this package's nested reference location. Its operative body and bundled
runtime materials are otherwise retained. `mahiro-style` remains the code-taste owner. No
executable prose/code lint rules are copied or required.
